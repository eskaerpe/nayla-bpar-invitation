# Nayla’s Sweet Seventeen

A warm, typography-led invitation for Nayla’s Sweet Seventeen.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) for the invitation and [http://localhost:3000/rsvp](http://localhost:3000/rsvp) for the RSVP flow.

Event time, address, dress code, personal note, and activities remain hidden until owner-supplied content is available. Menu choices are sourced from `MENU_BRACI.md`.
